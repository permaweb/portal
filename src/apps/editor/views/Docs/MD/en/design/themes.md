# Themes

Themes control the colors and corner shape of your portal. Each portal uses one compact theme with a light palette and a dark palette.

#### Edit Your Theme

1. Open **Design** from the portal editor.
2. Select **Themes**.
3. Edit the light and dark palettes.
4. Review the preview for each appearance.
5. Select **Save Changes**.

Use **Reset** to discard unsaved changes.

#### Theme Colors

Each appearance uses the same controls:

- **Background**: The page behind your content.
- **Surface**: Navigation, cards, and content panels.
- **Text**: Body copy, headings, and labels.
- **Accent**: Buttons, highlights, and active states.
- **Links**: Links and inline navigation text.
- **Border**: Dividers and component outlines.

Click a swatch to use the color picker or enter a hexadecimal color value.

Portal automatically derives muted text, hover colors, contrasting button text, and other component states from this palette. This keeps the portal consistent without requiring separate settings for every component.

#### Light and Dark Appearance

Configure both palettes even if you normally use only one appearance. Readers can follow their device appearance preference, and the portal will use the corresponding palette.

The preview below each palette shows how navigation, text, links, cards, borders, and buttons work together before you save.

#### Corner Radius

The **Corner Radius** control applies a consistent radius to cards, inputs, code blocks, and panels. Choose `0px` for square corners or increase the value for a softer appearance.

#### Choosing Accessible Colors

- Keep strong contrast between **Text** and both **Background** and **Surface**.
- Make sure the **Accent** and **Links** are visible against both background colors.
- Avoid using color alone to communicate status or meaning.
- Check both previews before saving.

Existing portals with the previous detailed theme format continue to render correctly. When you save from the simplified editor, Portal converts that theme to the compact palette automatically.
